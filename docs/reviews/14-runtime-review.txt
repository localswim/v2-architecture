Cross-layer traces
- Mutation/conflict: authenticated principal and explicit board target reach Go
  admission. Candidate validation, current rights/evidence and board/policy/card
  revision fences precede one state/audit/operation outcome commit. Stale or
  unauthorized requests change neither domain state nor successful-change audit.
- Upload: bounded, reauthorized staging verifies complete bytes before a fenced
  manifest commit. Incomplete references are forbidden; uncertain or retained bytes
  survive cleanup. Reference removal precedes retention-qualified deletion.
- Lost response/restart: transport failure does not prove cancellation. Correlated
  evidence determines committed/not-committed; missing or expired evidence remains
  indeterminate. Restart first acquires physical aggregate exclusion, validates
  saved state and intent, then admits complete revisions. Unknown writes stay fenced.
- Drain/children: admission closes before settling storage. Deadline expiry cannot
  authorize ownership release while writes may commit. Captured-child authority,
  quiescence and external-effect reconciliation supplement process generations;
  unresolved worker scopes can remain disabled while demonstrably safe local work
  resumes. Git publication remains separate from local commitment.
