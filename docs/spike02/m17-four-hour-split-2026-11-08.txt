Exact boundaries and conserved scope
- Inspector is a deliberate, fresh, uncached selected-board observation of eligible native candidate / missing / unqualified. No process is invoked. No version, supported/OK, policy-ready, capability, raw path/hash/account/target/error, persistence, history, polling, Copy or new selector surface.
- Current physical identity and authority are checked around native metadata work and again before disclosure. No native I/O under the short memory gate. Inspector observations never confer future invocation authority.
- I.01 reviewed full model precedes native preparation. Complete independent inspector seam review I.09a precedes I.07; final component/client review I.09b follows I.08. Dormant native code is not the user-facing milestone outcome.
- II.01-.03 complete the entire original safety/control/seam bundle. II.05a independent native/source-safety PASS precedes II.04 actual installed literal invocation. II.05b evidence closure precedes II.06 clients. Material code findings repeat source review and affected proof.
- Before every actual invocation: trusted pinned native codex.exe provenance/identity/hash rechecked; frozen literal argv, closed stdin, private working directory and necessary environment. No caller command/path/argv/environment or shell wrapper.
- Preserve suspended-root nonbreakaway job/kill-on-close,16 processes including root,64KiB combined capture,10s command deadline plus2s foreground drain reporting, one probe per physical board, zero automatic queue. Retain exclusion/ownership until actual root/descendant/pipe/handle join; incomplete never means success or release.
- Preserve current authority/generations, safe finite outcomes, denied-late redaction, fixed recipient configuration, local notice originals/targets/cuts/receipts, archive/restore lineage and UNKNOWN/no replay. No M18 capability, Send/Enable/Start, new transport/nudge, retarget, shared-host action or watcher revival.
- Only actual qualified literal identity output with complete parse/zero exit/actual joined closure yields positive version; controlled fixtures cannot certify the installed tool. Missing/unsupported actual interface remains a concrete readiness issue.
- Future implementation needs owner approval, fresh scoped estimates/preflight and In Progress entry. This plan authorizes no execution. Terry alone controls Completed.
- Preflight applicability: M17A performs no actual product probe and makes no installed-version support claim. M17B preflight checks its already-shipped baseline; its new literal identity proof is II.04 after II.05a source-safety PASS. Capability probing remains a later milestone. Neither applicability rule excludes any already-shipped baseline case.
