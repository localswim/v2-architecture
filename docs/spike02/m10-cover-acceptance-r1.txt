Actual CLI write sequence

Run this shape in PowerShell 7 with a live synthetic host, an existing private
run directory and IDs from ordinary reads. A second operation uses a deliberate
fresh current read, new private input path and a fresh opId. For clear pass
$null as $coverId. Use a new path for each original, including refusals.

  $selection = @('--workspace', $workspace, '--project', 'harbor', '--board', 'dispatch')
  $raw = & $exe @selection --json card read $cardId
  if ($LASTEXITCODE -ne 0) { throw 'Current read failed' }
  $current = ($raw | ConvertFrom-Json).result
  if ($current.card.cardId -cne $cardId) { throw 'Wrong current card' }
  $request = @{
    opId = [guid]::NewGuid().ToString()
    incarnation = $current.identity.incarnation
    target = @{ cardId = $cardId }
    expectedRevision = $current.revision
    expectedCardRevision = $current.card.revision
    input = @{ coverAttachmentId = $coverId }
  }
  $inputFile = Join-Path $privateRun ($request.opId + '.json')
  $request | ConvertTo-Json -Depth 8 | Set-Content -LiteralPath $inputFile -Encoding utf8NoBOM
  & $exe @selection --json card edit $cardId --input $inputFile
  $mutationExit = $LASTEXITCODE
