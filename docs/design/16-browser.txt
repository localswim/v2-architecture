Recommendation and alternatives

Choose semantic HTML plus narrowly owned controllers, avoiding a second domain
model. These are design alternatives, not verified library claims or a dependency
selection for22. Reconsider after representative drawer/search/move accessibility
qualification; package size and responsiveness remain unmeasured. No CDN/fonts or
remote assets are required. Local assets permit rendering the shell during transport
failure; they confer neither offline mutation authority nor guaranteed reload access.

Routes identify resources, never credentials or card prose; use per-window local
search text where URL disclosure would expose content. Browser history restores
selection/filter context and focus, not mutations. A drawer route opens directly
when authorized; unknown/inaccessible identities show a bounded unavailable state.
Workspace discovery/navigation is a consumer boundary; it grants no board access.

State and concurrency
Cache only validated projections keyed by instance, principal scope, board, query
and committed revision. Go supplies rights, order, triage explanations and archive
semantics; filtered results never redefine global counts. Drafts are separate,
keyed by board/card or creation identity and editor kind, retaining base board/policy/
card revisions. Never replace dirty fields during refresh. Comments and relationship
forms have independent drafts; changing a reference or precondition changes intent.

Keep drafts and unresolved operation identities/fingerprints in tab memory across
navigation. Recommend explicit opt-in private draft recovery storage with retention
and clear controls, excluding sessions/request tokens/grants; qualify confidentiality
and reload behavior before enabling it. In-memory-only mode cannot promise crash
recovery. Host replacement uses a new origin: preserve the old tab's drafts, offer
user-directed private recovery transfer, then rebind only after authentication and
explicit resource/revision reconciliation. Never automatically trust imported drafts.

Each read carries a navigation epoch and query/resource key; discard a late response
unless both still match. Abort superseded reads and debounce search, but guard late
responses even after cancellation. Notifications invalidate cache entries; reconnect
refreshes health/revisions and reconciles operations before offering new submissions.

A mutation journal captures immutable target, principal, operation identity,
fingerprint and preconditions before submission, separate from transport request IDs.
Navigation cannot retarget it. Cancellation/timeouts do not prove rollback. Use32's
reconciliation mode; missing/expired evidence remains indeterminate. Committed results
update only their original resource and preserve subsequent draft edits. Deliberate
resubmission uses new intent/identity after review; expose possible duplication while
an older effect remains unresolved. Never silently replay, merge or regenerate IDs.

Interaction/recovery matrix
Interaction | Presentation and recovery obligation
Cards/drawers/create/edit/comments | Explicit save; retain drafts on refusal/conflict; compare refreshed revisions and request deliberate resolution. Closing restores trigger focus or a stable board heading if absent.
Search/archive/relationships | Revision-bound results; archived links remain navigable/labeled; show server explanations and atomic relationship effects, including hidden cards. Preserve form/search context.
Pointer/keyboard moves | Equivalent labeled move action and keyboard destination chooser; announce result and restore focus by stable ID. Show pending intent without claiming committed lane/order; conflict restores authoritative placement.
Attachments | Explicit selection/upload/staging status; bounded byte controls; manifest success only after server commitment. Preserve uncertain upload outcome; inert download/preview treatment and reference removal follow12/13, with physical retention server-owned.
Review acceptance | Present reviewed revision and server capability; explicit acceptance command binds card/policy revisions. Stale review requires renewed inspection; browser presence/actor labels never confer human authority.
Status/recovery | Distinguish loading, retained stale reads, write-disabled/quarantine, auth loss, conflict and indeterminate outcome. Show local commit independently from Git publication; accessible live announcements avoid stealing focus.

Session and adapter boundary
Use13's pinned generated declarations plus a thin adapter validating responses,
errors and event envelopes at runtime; generated types confer no authority. Keep32's
session-bound token only in memory and attach its custom header to every protected
read/command/fetch-stream request, with cookie and required same-origin context.
No native credentialless event fallback. Public bootstrap assets grant no protected
access. Revocation/replacement stops streams and admissions; reauthentication follows
the trusted launcher exchange and never replays commands. Do not move credentials
or requests to a discovered alternate origin.
